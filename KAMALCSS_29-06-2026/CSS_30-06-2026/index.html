Child Element
overflow:hidden
This is a very long paragraph. The extra text that does not fit inside the box will be hidden because the overflow property is set to hidden.
overflow:visible
This is a very long paragraph. The content is larger than the box, so it continues outside the box because the overflow property is set to visible.
,overflow:scroll
This is a very long paragraph. Since the content is larger than the box, you can scroll to read all of it. The scrollbars are always visible when overflow is set to scroll.
overflow:auto
This is a very long paragraph. Scrollbars appear only if the content exceeds the size of the box. If all content fits, no scrollbars are displayed.
